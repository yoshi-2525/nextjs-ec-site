お気に入り機能を追加しよう

作成したECサイトにお気に入り機能を追加する課題です。

180分

普通

12人が合格

未提出

​​本課題の目標

本課題の目標は以下のとおりです。

  • ECサイトにお気に入り機能を追加すること

課題の内容

ECサイトの 一般ユーザーが気になる商品をお気に入り登録し、あとから一覧ページで閲覧できる機能 を実装してください。実装項目は以下のとおりです。

  • お気に入り登録／取得／削除API

    • 一般ユーザーが追加したお気に入り情報をデータベースに登録する。
    • 特定ユーザーに紐づく全お気に入り情報をデータベースから取得する。
    • 特定商品・特定ユーザーに紐づくお気に入り情報をデータベースから取得する。
    • 一般ユーザーが解除したお気に入り情報をデータベースから削除する。

  • お気に入り一覧ページ

    • ヘッダーのハートアイコンまたはマイページの「お気に入り商品の確認」から遷移可能。
    • ログインユーザーが追加したお気に入り商品をカード形式で表示する。
    • ページネーションの実装は不要。
  • 商品詳細ページのお気に入りリンクの制御
    • お気に入り追加有無に応じて表示するリンクを切り替える

      • 追加済みの場合：♥ お気に入り解除

      • 未追加の場合：♡ お気に入り追加

作業手順は後述の各Stepを参照しましょう。

課題の作業手順

Step1. favoritesテーブルを追加する

まずは、お気に入り情報を管理するための favoritesテーブル を追加します。手順は以下のとおりです。

  1. phpMyAdminでnextjs_samuraistoreデータベースを選択する
  2. 「SQL」タブを開く
  3. 以下のCREATE TABLE文をコピーアンドペーストする
1CREATE TABLE favorites (
2    id INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
3    product_id INT NOT NULL,
4    user_id INT NOT NULL,
5    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
6    UNIQUE (product_id, user_id),
7    FOREIGN KEY (product_id) REFERENCES products(id),
8    FOREIGN KEY (user_id) REFERENCES users(id)
9);
Copy
  1. 少し下にスクロールし、「実行」をクリックする

以下のように、favoritesテーブルが追加されていればOKです。

Step2. 必要なファイルとフォルダを作る

次に、VS Codeでお気に入り機能に必要なファイルとフォルダを作りましょう。具体的には、以下のファイル・フォルダを作ってください。（）内は、追加先のパスです。

追加対象のファイルとフォルダ用途
（src/app/account/） favorites/page.tsxお気に入り一覧ページ
（src/app/products/[id]/） FavoriteControls.tsxお気に入り制御用コンポーネント
（src/app/api/） favorites/route.tsお気に入り登録／全取得API
（src/app/api/） favorites/[id]/route.tsお気に入り個別ID取得／削除API

Step3. お気に入り登録／全取得APIを実装する

続いて、/api/favorites/route.tsファイルにお気に入り登録／全取得APIを実装しましょう。以下の仕様に沿って、 GET()関数とPOST()関数 を実装してください。

関数名説明
GET()ログイン者のユーザーIDに紐づくお気に入りデータ（全カラム）を、favoritesテーブルから登録日時が新しい順に取得する。
POST()送信されたお気に入りデータをfavoritesテーブルに登録する。登録済みの場合は登録をスキップし、成功扱いとする。

なお、 INSERT IGNORE INTO文 を使うことで、すでに登録されているデータの追加をスキップできます。

Step4. お気に入り個別ID取得／削除APIを実装する

次に、/api/favorites/[id]/route.tsファイルにお気に入り個別ID取得／削除APIを実装しましょう。以下の仕様に沿って、 GET()関数とDELETE()関数 を実装してください。

関数名説明
GET()商品IDとログイン者のユーザーIDに紐づくお気に入りデータが存在するかチェックし、その結果を返す。
お気に入りが見つかった場合：true<br>お気に入りが見つからなかった場合：false
DELETE()指定されたIDのお気に入りデータをfavoritesテーブルから削除する。

Step5. お気に入り制御用コンポーネントを実装する

続いて、/products/[id]/FavoriteControls.tsxファイルにお気に入り制御用コンポーネントを実装しましょう。ここでは、以下の要件を満たすように実装してください。

  • お気に入り追加有無に応じて表示する文言を切り替える

    • 追加済みの場合：♥ お気に入り解除

    • 未追加の場合：♡ お気に入り追加

  • お気に入り追加有無に応じたAPIリクエストを送信する

    • お気に入り追加が押された場合：POSTリクエスト
    • お気に入り解除が押された場合：DELETEリクエスト

  • お気に入りリンクがクリックされるたびに、反対のお気に入り状態に切り替える

  • お気に入りリンクの初期文言は、propsで渡されたものを設定する

  • お気に入りリンクが押されてから処理が完了するまでの間は、リンクを無効化する（disabled属性で設定）

なお、デフォルトのフォントだと、ハートの種類によっては小さく表示されてしまいます。

見やすい大きさでハートマークを表示するために、お気に入りリンクには以下のスタイルを設定し、フォントを切り替えましょう。

1style={{ fontFamily: 'sans-serif' }}
Copy

Step6. 商品詳細ページを修正する

続いて、商品詳細ページを修正しましょう。ここでは、以下の要件を満たすように実装してください。

  • 商品IDに紐づくお気に入り状態をデータベースから取得する（商品やレビューの取得と並行）
  • FavoriteControlsコンポーネントを呼び出し、お気に入りリンクを表示する

注意点として、お気に入りAPI内部ではユーザー情報の取得が必要です。このとき、JWTのトークンを使用するため、クッキーに含めて送る必要があります。

しかし、商品詳細ページのようなサーバーコンポーネントでは、 クッキーがサーバー側へ自動的には送られません。 そのため、以下のように明示的なクッキー送信処理が必要です。

1// クッキーを取得
2const cookieStore = await cookies();
3const token = cookieStore.get(AUTH_TOKEN)?.value;
4const headers: HeadersInit = token ? { 'Cookie': `${AUTH_TOKEN}=${token}` } : {};
5
6// お気に入り取得APIから商品IDの登録有無を取得
7const res = await fetch(`${process.env.BASE_URL}/api/favorites/${id}`, {
8  cache: 'no-store',
9  headers: headers,
10});
Copy

このように、JWTトークンを含めたクッキーをfetch()メソッドのheadersに設定してください。こうすることで、サーバー側でユーザー情報を取得できるようになります。

Step7. お気に入り一覧ページを実装する

次に、/account/favorites/page.tsxファイルにお気に入り一覧ページを実装しましょう。細かいデザインや実装方法は問いませんが、以下のすべてを実装しましょう。

  • 「マイページへ戻る」リンク
  • お気に入り一覧ページであることがわかる文言（h1）
  • お気に入り商品（カード形式）：以下4つを各商品に対して設置
    • 商品画像（120×120）
      • クリックすると該当商品の商品詳細ページへ遷移
    • 商品名
    • 価格
    • カートに追加ボタン
      • 商品を1つカートに追加（数量選択は不要）
      • 追加後は「追加済み」として無効化する
    • お気に入り解除ボタン
      • 「本当にお気に入りから削除しますか？」と確認を求め、「OK」が選択された場合にお気に入り一覧から削除

以下は表示イメージです。これと完全に同じでなくても問題ありません。

Step8. 動作をチェックする

最後にブラウザでお気に入り機能の動作をチェックしましょう。VS Codeのターミナルでsamurai-storeプロジェクトに移動し、開発サーバーを起動してください。

1cd 【samurai-storeプロジェクトのフォルダパス】
2npm run dev
Copy

また、XAMPPまたはMAMPを使い、MySQLデータベースを起動しておきましょう。

まずは、以下のURLからログインページへアクセスしてください。

1http://localhost:3000/login
Copy

以下の入力によりログインしましょう。

入力項目入力値
メールアドレスtaro.samurai@example.com
パスワードpassword

ログイン後、任意の商品画像をクリックし、商品詳細ページを開きましょう。そして、お気に入りリンクをクリックしてください。

以下のように、「お気に入り解除」に変更されればOKです。

次に、アカウントアイコンのメニューから 「マイページ > お気に入り商品の確認」 の順に遷移してください。以下のように、追加したお気に入り商品が表示されればOKです。

また、以下の確認も行いましょう。

  • カートに追加ボタンで該当商品をカートに追加できること
  • お気に入り解除ボタンで該当商品をお気に入りから除外できること
  • お気に入り追加後や解除後に、商品詳細ページのお気に入り状態が保持されていること
  • お気に入り一覧ページの商品画像をクリックして商品詳細ページへ遷移できること
  • phpMyAdmin上でもfavoritesテーブルの中身が正しく変化していること

合格基準

本課題の目標は、課題を通して以下の項目が身についているかどうか図ることです。

  • Next.jsを用いたフロントエンド・バックエンドの基本的な実装ができること

そのため、以下の項目がすべて満たされていれば合格です。

番号合格基準
1商品詳細ページのお気に入りリンクが仕様どおりに制御される。
2ユーザー操作に応じてお気に入りデータが更新（登録／削除）される。
3お気に入り一覧ページにユーザーの登録内容が不整合なく表示される。
